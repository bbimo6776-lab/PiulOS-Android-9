# PiulOS Android 9 Source Plan

Target device: Samsung Galaxy J2 Core SM-J260F
Android base: Android 9 Pie

Required source components:
1. Android 9 platform source
2. Exact device configuration for SM-J260F
3. Compatible Exynos 7570 kernel source
4. Matching device tree
5. Required vendor components
6. Build environment compatible with Android 9

Current state:
- Project configuration files exist
- QEMU prototype exists separately
- Android platform source is not downloaded
- Device-specific kernel is not built
- No installable ROM exists yet

Do not label project files as a release ROM until
the system has been built and its outputs verified.
