# PiulOS Test Plan

1. Confirm exact device model and hardware compatibility.
2. Validate the Android source and device configuration.
3. Build the kernel in a compatible environment.
4. Build the Android system and boot image.
5. Verify image formats, partition sizes, and checksums.
6. Review boot logs and hardware functionality.
7. Do not test by flashing unverified images.

Preserve existing user data throughout development.
