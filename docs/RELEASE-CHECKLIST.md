# Release Checklist

[ ] Android 9 platform source acquired
[ ] Exact target device tree verified
[ ] Kernel source and defconfig verified
[ ] Vendor components obtained legally
[ ] Build environment validated
[ ] System image compiled
[ ] Boot image compiled
[ ] Image formats and partition sizes checked
[ ] Checksums recorded
[ ] Hardware compatibility tested
[ ] Recovery and data-preservation plan reviewed

Until all required steps are complete, PiulOS is not a release ROM.
